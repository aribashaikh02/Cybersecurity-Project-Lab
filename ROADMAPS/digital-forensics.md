# Digital Forensics Basics Roadmap

1. Learn evidence integrity, documentation, and chain-of-custody concepts.
2. Practice hashing sample files with SHA-256.
3. Inspect basic file metadata in a controlled folder.
4. Learn timestamps, time zones, and timeline construction.
5. Use disk images and forensic tools only in authorized training labs.
6. Record tool versions, commands, timestamps, and observations.
7. Keep originals unchanged and work from copies where appropriate.
8. Clearly distinguish observed facts from assumptions in reports.
