# Cybersecurity Foundations Roadmap

1. Learn operating-system basics, files, permissions, processes, and the command line.
2. Learn networking: IP addresses, DNS, TCP/UDP, HTTP/HTTPS, ports, and routing.
3. Learn Python basics: variables, functions, files, exceptions, and modules.
4. Understand confidentiality, integrity, availability, authentication, and least privilege.
5. Practice only in intentionally vulnerable labs or systems you have permission to test.
6. Document each lab: goal, setup, steps, observations, remediation, and limitations.
7. Learn how to read logs and write clear incident notes.
8. Build a small defensive tool and add tests and a clear README.
