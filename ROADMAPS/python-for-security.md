# Python for Security Roadmap

1. Syntax, strings, collections, conditions, loops, and functions.
2. File handling, paths, exceptions, and JSON/CSV.
3. Modules including `hashlib`, `argparse`, `pathlib`, and `logging`.
4. Write small tools with clear command-line arguments.
5. Add tests, input validation, and error handling.
6. Learn HTTP requests and APIs using authorized targets and public test data.
7. Parse synthetic logs and create structured reports.
8. Document limitations and never store secrets in source control.
