# Password Strength Checker

A local, rule-based password feedback tool. It checks length and character variety and gives suggestions. It does not save, transmit, or log the supplied password.

## Run

```bash
python password_checker.py
```

Enter a test password when prompted. For safety, use a sample password rather than a real password you use for an account.

## Important
This is an educational heuristic, not a password-cracking tool or a guarantee of security. Use a password manager and unique passphrases; never share actual passwords.
