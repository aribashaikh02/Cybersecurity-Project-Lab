# Beginner Projects

Project ideas for the next development stage. Add each project in its own folder with working code, a project README, examples, tests where useful, and safe-use guidance.

- HTTP Security Header Checker — check a website you own or are authorized to assess.
- File Metadata Reporter — report metadata from user-selected local files.
- Suspicious URL Awareness Checker — explain common URL warning signs with transparent rules.
- Linux Permission Auditor — inspect a designated local test directory.
