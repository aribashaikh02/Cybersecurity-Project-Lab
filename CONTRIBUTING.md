# Contributing

Thanks for helping improve Cybersecurity Project Lab!

## Before contributing
- Check existing issues and project folders to avoid duplicate work.
- Keep examples safe and suitable for a local lab.
- Do not add credentials, private data, malware, or instructions targeting systems without permission.
- If code or assets are adapted from another source, document the source and license.

## Pull request checklist
- [ ] Explain what changed and why.
- [ ] Include setup and test instructions.
- [ ] Update the relevant README.
- [ ] Add tests or sample inputs when useful.
- [ ] Verify that no secrets or personal data are included.
